# Product Requirements Document (PRD)

## Product Name
**Polaris**

## Target Audience
Anindita Sarker (Solo-developer / Single-user focus).

## Vision
To create a "Life RPG" dashboard that merges productivity, personal development, and gamification into a single, beautiful, space-themed interface. It should act as a central command center for all aspects of life.

## Core Requirements
1. **Visual Map**: A way to visualize the high-level domains of life (Constellation Graph).
2. **Action Management**: A focused workspace to track what needs to be done *today* without being overwhelmed by the backlog (Focus Board).
3. **Habit Building**: A way to track recurring daily routines with positive reinforcement (Rituals).
4. **Gamification**: An XP and Leveling system to reward productivity.
5. **External Sync**: Integration with Google Calendar to prevent data silos.
6. **Longevity Tracking**: Features to track long-term milestones (Timeline) and media consumption (Curriculum/Media Log).
7. **Social Management**: A lightweight CRM to remember to reach out to people.

## Non-Functional Requirements
- **Performance**: The app must be fast and responsive, built as an SPA.
- **Aesthetics**: Must adhere strictly to the dark, space-themed design language (glassmorphism, vibrant accents).
- **Responsive**: Must work flawlessly on both Desktop (HUD) and Mobile (Bottom Nav).
