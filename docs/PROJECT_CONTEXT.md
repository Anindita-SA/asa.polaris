# Project Context

Polaris is a highly customized, personal life-management dashboard designed specifically for Anindita Sarker.

It is not a commercial SaaS product meant for public release, but rather a "Life RPG" that centralizes various aspects of daily living—from academic research and career portfolios to fitness, relationships, and leisure.

The name **Polaris** refers to the North Star, acting as a metaphor for a guiding system that helps the user stay aligned with their long-term goals while navigating the day-to-day chaos.

By utilizing a space-themed aesthetic and gamified mechanics (XP, Levels, randomizers), Polaris transforms mundane tasks into engaging quests.
