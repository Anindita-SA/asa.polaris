Consolidate the Leaky Offline Persistence Seam

Strong ports & adapters

Problem:

Offline mutations leak validation rules, dynamic DLQ imports, and queue draining across four shallow modules with circular imports.

Solution:

Deepen the persistence layer into a single DataSyncEngine module that encapsulates Dexie storage, payload validation, and DLQ resolution behind one uniform interface.

Wins:

  • • Locality: validation concentrates in one module
  • • Leverage: one interface for all storage
  • • Deletes circular dynamic imports in loops
  • • Two clean adapters: Supabase and Memory

Unify Multi-Table Task Ingestion in useTodaysTasks

sequenceDiagram
    participant Hook as useTodaysTasks.js

    Store-->>Repo: unified records with subtask counts

Problem:

useTodaysTasks downloads every task the user has ever created into client memory to calculate subtask ratios and active statuses.

Solution:

Deepen task querying behind a TaskRepository module that returns pre-aggregated parent-child task records through a single interface call.

Wins:

  • • Leverage: 1 query replaces 3 fetches
  • • Eliminates client memory scan of full history
  • • Locality: aggregation lives in data layer
  • • Test surface: mock 1 call, not 3 tables
