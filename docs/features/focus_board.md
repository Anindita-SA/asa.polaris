# Focus Board & Backburner

## Overview
The Focus Board enforces priority discipline by limiting active cognitive commitments to a strict maximum of 3 concurrent projects. It pairs active execution with a structured Backburner where deferred concepts are preserved alongside rich context snapshots.

## Architecture & Workflows

### 1. Active Focus (Max 3 Items)
- **Constraint Enforcement**: Prevents cognitive overload by capping in-progress initiatives at 3.
- **Why Now Rationale**: Every active item must define an explicit "Why Now" justification highlighting near-term leverage or immediate deadlines.
- **Drag-and-Drop Reordering**: Visual drag handles allow prioritizing the 1st, 2nd, and 3rd focus items dynamically.

### 2. Backburner & Context Snapshots
- **Idea Preservation**: High-potential ideas can be safely parked without cluttering daily workflows.
- **Context Snapshot**: Captures background research, decision trade-offs, and next physical actions at the moment of deferral.
- **Revisit Timestamps**: Optional review dates remind the user when a deferred initiative is ready to be re-evaluated.
- **Seamless Promotion**: One-click promotion from Backburner to Active Focus once an active slot clears.
